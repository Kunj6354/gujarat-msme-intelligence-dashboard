# M4 — Power BI Desktop Build and Visual Acceptance

## Objective

Build the actual PBIX report from the validated Gujarat real-data
candidate release and document visual acceptance evidence.

## Required software

Power BI Desktop on Windows.

## Controlled data source

Use only:

`powerbi/m4_build_workspace/input/gujarat_district_msme.csv`

## PBIX output

`powerbi/pbix/StackOre_Gujarat_MSME_Dashboard_retrieved_2026-07-30_v1.pbix`

## Build order

1. Configure the semantic model.
2. Import the supplied theme.
3. Create the DAX measure table and measures.
4. Build Gujarat Executive Overview.
5. Build District Comparison.
6. Build Enterprise Category Analysis.
7. Build Data Availability and Limitations.
8. Build Sources and Methodology.
9. Build District Tooltip.
10. Build District Detail drill-through.
11. Test visual interactions.
12. Capture screenshots.
13. Complete acceptance results.
14. Validate all KPI values against the M4 baseline.
15. Submit the PBIX and evidence for review.

## Approval condition

M4 is complete only when the PBIX, seven screenshots, page-status
record, acceptance results and KPI verification are all available.

Public publication remains disabled.
